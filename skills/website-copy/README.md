# website-copy

Write high-converting, brand-consistent website copy.

## Why

Every word on your site either earns its place or gets ignored. website-copy enforces the craft: voice triangle (bold/clear/conversational), headline formulas, CTA hierarchy, microcopy patterns, and the read-aloud test.

## Install

```bash
clawhub install website-copy
```

## Quick start

```
Use website-copy to rewrite the gocrewwai landing page copy.
```

The skill returns:
- A voice triangle (bold / clear / conversational)
- Headline templates that name outcome, imply effortlessness, create specificity
- Subheadline and CTA hierarchy rules
- Microcopy patterns for empty states, errors, confirmations
- A "sounds like a human" test
- A conversion checklist with 12 items

See `SKILL.md` for the full voice system, headline formulas, and the buzzword audit script.
