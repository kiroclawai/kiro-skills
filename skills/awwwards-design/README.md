# awwwards-design

Design websites at Awwwards-winner quality.

## Why

Most websites look fine. Few feel premium. The gap is craft: typography, motion, color restraint, spacing rhythm, and the deliberate hover state. awwwards-design encodes the eight disciplines shared by award-winning sites so you can apply them without the years.

## Install

```bash
clawhub install awwwards-design
```

## Quick start

```
Use awwwards-design to redesign the gocrewwai landing page.
```

The skill returns:
- A typographic scale (display → mono) with letter-spacing tuned
- A semantic color token system (light + dark)
- A 4px spacing scale and breathing rhythm
- Motion guidelines (durations, easing curves, stagger)
- Hover states with `transform: scaleX()` underline draws
- A page composition template (hero → social proof → problem → product → proof → pricing → footer)
- A "premium" checklist with 11 items

See `SKILL.md` for the full eight disciplines and reference sites worth studying.
