# git-arsenal

Advanced Git workflow automation for professional developers.

## Features

- **Branch Cleanup** — Interactive cleanup of merged/stale branches with safety checks
- **Smart Commits** — Generate conventional commit messages from diff analysis
- **Release Prep** — Tag, changelog, and release notes in one command
- **Conflict Assist** — AI-powered merge conflict resolution suggestions
- **Repo Doctor** — Audit for large files, secrets, broken refs

## Quick Start

```bash
# Install
openclaw skills install git-arsenal

# Clean merged branches
git-arsenal clean --merged

# Generate smart commit message
git-arsenal commit --execute

# Prepare a release
git-arsenal release minor

# Fix merge conflicts
git-arsenal conflicts

# Audit repo health
git-arsenal doctor
```

## Why This Skill

Git is powerful but tedious. git-arsenal automates the repetitive parts:
- No more typing conventional commit messages manually
- No more forgetting to clean up feature branches
- No more manual changelog generation
- No more struggling with merge conflicts alone
